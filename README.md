# GenAI Developer Roadmap 2026 🚀

A mobile-first progress tracker for the Generative AI Developer learning path — based on real 2026 job market data.

## Features

- ✅ 7 phases, 50 topics mapped to actual job requirements
- 🔥 Priority tags (CRITICAL / HIGH / MEDIUM) per topic
- 📊 Stats view with phase-by-phase breakdown
- 💼 Job Guide with salary ranges for each career level
- 📝 Add notes to any topic
- 💾 Progress auto-saves in browser (localStorage)
- 📱 Works as iPhone home screen app (PWA-ready)

## Deploy to GitHub Pages (5 min)

### Step 1 — Create repo

1. Go to [github.com](https://github.com) → click **New repository**
1. Name it `genai-roadmap` (or anything you like)
1. Set to **Public**
1. Click **Create repository**

### Step 2 — Upload the file

1. In your new repo, click **Add file → Upload files**
1. Drag in `index.html`
1. Click **Commit changes**

### Step 3 — Enable GitHub Pages

1. Go to repo **Settings → Pages** (left sidebar)
1. Under **Source**, select **Deploy from a branch**
1. Branch: `main` / Folder: `/ (root)`
1. Click **Save**

### Step 4 — Get your URL

After ~60 seconds your site is live at:

```
https://YOUR-USERNAME.github.io/genai-roadmap/
```

### Step 5 — Add to iPhone home screen

1. Open the URL in **Safari**
1. Tap the **Share** button (box with arrow at bottom)
1. Tap **“Add to Home Screen”**
1. Tap **Add** — done! 🎉

It now lives on your home screen like a native app, with progress saved between sessions.
